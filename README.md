# AI Video Generator

Vercel-native production architecture for a multimodal AI video-generation platform based on the open-source Open Generative AI project.

## Architecture
GitHub → Vercel → Next.js App Router → React + TypeScript → PostgreSQL/Prisma → durable generation workflow → object storage → external AI video providers.

## Production principles
- Vercel-native stateless execution
- Durable PostgreSQL generation state
- Durable media storage
- Provider-independent orchestration
- Server-only privileged credentials
- Immutable credit ledger foundation
- Super-admin cost accounting
- Future Stripe subscription/credit architecture
- Vercel Analytics and Speed Insights
- MIT upstream attribution preserved

See `VERCEL_DEPLOYMENT.md` for deployment requirements.
