# Upstream attribution

This project is a Vercel-native derivative architecture inspired by and incorporating concepts from **Open Generative AI** by Anil Matcha and contributors:

https://github.com/Anil-matcha/Open-Generative-AI

The upstream project is MIT licensed. The original MIT notice is retained in `LICENSE`.

Production architecture intentionally excludes runtime dependence on Electron, local inference binaries, local filesystem persistence and long-lived desktop processes.
